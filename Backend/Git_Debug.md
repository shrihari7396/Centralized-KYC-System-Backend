## 🟢 Step 1: Stash your changes (IMPORTANT)

```bash
git stash
```

👉 This temporarily saves your changes safely

---

## 🟢 Step 2: Pull latest code

```bash
git pull origin main
```

---

## 🟢 Step 3: Bring your changes back

```bash
git stash pop
```

---

## ⚠️ If conflicts appear

Resolve them → then:

```bash
git add .
```

```bash

```
